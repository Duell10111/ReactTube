# ReactTube - Local Apple TV Build

This guide builds ReactTube for Apple TV with Expo and Xcode. For iPhone/iPad,
including free Personal Teams and Siri builds, use the [iOS build guide](docs/IOS_LOCAL_BUILD.md).

## Prerequisites

- Node.js (LTS) and npm
- Xcode with tvOS support
- Apple development signing configured in Xcode for a physical device

## Steps

1. Clone the repository and install dependencies:

   ```bash
   git clone https://github.com/Duell10111/ReactTube.git
   cd ReactTube
   npm install --legacy-peer-deps
   ```

2. In `app.json`, set `isTV` to `true` for both the `@react-native-tvos/config-tv` and `./plugins/ios/withAppleTargets.js` plugins. Keep the other plugin settings, including the current tvOS deployment target and image paths, as they are. The local wrapper forwards the team/TV options to `@duell10111/apple-targets`. It and the Siri plugin always exclude Siri from TV builds, regardless of `enabled`; the Watch target is also excluded on tvOS. The build workflow sets TV mode by plugin name and explicitly disables Siri before its clean prebuild.

3. Generate the tvOS Xcode project:

   ```bash
   npx expo prebuild -p ios --clean
   ```

4. Open `ios/reacttube.xcworkspace` in Xcode. Select the `reacttube` scheme and an Apple TV simulator or connected device. Configure signing for a physical device, then build and run.

The `ios/` directory is generated by prebuild; do not commit it. Switching between TV, phone and Siri variants always requires a clean prebuild. The unsigned CI artifact is named `reacttube-tvos-no-siri.ipa` and needs appropriate signing before installation on a physical Apple TV.
