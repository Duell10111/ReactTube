# ReactTube - Local Apple TV Build

This guide builds ReactTube for Apple TV with Expo and Xcode.

## Prerequisites

- Node.js (LTS) and npm
- Xcode with tvOS support
- Apple development signing configured in Xcode for a physical device

## Steps

1. Clone the repository and install dependencies:

   ```bash
   git clone https://github.com/Duell10111/ReactTube.git
   cd ReactTube
   npm install --legacy-peer-deps
   ```

2. In `app.json`, set `isTV` to `true` for both the `@react-native-tvos/config-tv` and `@duell10111/apple-targets` plugins. Keep the other plugin settings, including the current tvOS deployment target and image paths, as they are. The repository's build workflow makes the same two changes before prebuilding.

3. Generate the tvOS Xcode project:

   ```bash
   npx expo prebuild -p ios --clean
   ```

4. Open `ios/reacttube.xcworkspace` in Xcode. Select the `reacttube` scheme and an Apple TV simulator or connected device. Configure signing for a physical device, then build and run.

The `ios/` directory is generated by prebuild; do not commit it for a documentation-only change.
